# -DSA_Visualizer-Sorting-Searching-Algorithms-
## Project Description

This project is developed using C++.

The project demonstrates the working of sorting and searching algorithms through step-by-step visualization.

## Algorithms Implemented

### Sorting Algorithms
1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort

### Searching Algorithms
1. Linear Search
2. Binary Search

## Features

- User input array
- Random array generation
- Step-by-step visualization
- Comparisons count
- Swaps count
- Time complexity display
- Menu driven interface

## Technologies Used

- C++
- STL
- Dev C++

## Steps to Run

1. Open Dev C++
2. Open main.cpp
3. Compile and Run (F11)
4. Enter array size and elements
5. Select algorithm
